# 포토카드

이 폴더에 `버전_멤버이름` 형식으로 올리면 입덕 탭 '포토카드'에 버전별로 자동 정리돼요.

| 파일 이름 예 | 표시 |
|---|---|
| `SOUL_문.webp`, `CONSTELLATION_moon.jpg` | 버전 탭 'SOUL' / 'CONSTELLATION'에 MOON |
| `예판특전_메이크스타_문.webp` | 버전 탭 '예판특전'에 MOON · 메이크스타 |

- 첫 조각이 버전(탭 이름), 멤버 이름(한글·영문)은 어디에 있어도 OK, 나머지는 설명
- jpg·png·webp. 최애로 정한 멤버 카드가 맨 앞에 와요
- 올리는 법: GitHub에서 이 폴더 열기 → Add file → Upload files → 끌어다 놓기 → Commit
