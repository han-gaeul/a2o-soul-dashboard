# 멤버 사진

이 폴더에 **멤버 이름으로 된 사진 파일**을 올리기만 하면 자동으로 연결돼요. `members.yml`은 안 고쳐도 돼요.

| 파일 이름 | 쓰이는 곳 |
|---|---|
| `moon.jpg` 또는 `문.jpg` | 대표 사진 — 멤버 카드 아이콘, 프로필, 퀴즈 |
| `moon-2.jpg`, `moon_데뷔.jpg` … (이름 뒤에 `-`나 `_`) | 추가 사진 — 역대 프로필, 퀴즈 |

- 영문 이름은 대소문자 상관없음 (`MOON.jpg`도 OK). jpg·png·webp
- 올리는 법: GitHub에서 이 폴더 열기 → **Add file → Upload files** → 사진 여러 장 끌어다 놓기 → Commit
- 멤버 4명 이상 사진이 있으면 입덕 탭 퀴즈가 사진 퀴즈로 바뀌어요
- 공식 계정·소속사가 배포한 사진만, 출처 표기가 필요하면 `members.yml`의 `profile_history`에 `label`로
